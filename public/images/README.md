# Imágenes del libro

Pon aquí las imágenes de cada ingrédient. Se usan en la página si el ingrédient tiene el campo `image` en `src/data/ingredients.ts`.

**Beurre noisette:** pon un archivo llamado **`beurre-noisette.jpg`** (o `.png`) en esta carpeta.  
La ruta en datos es `/images/beurre-noisette.jpg`.

Para otros ingrédients, añade la imagen (ej. `nombre-ingredient.jpg`) y el campo `image: "/images/nombre-ingredient.jpg"` en los datos.
